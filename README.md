# BROKENtv 🚀📺

**O player IPTV mais lindo, moderno e funcional que você vai ver — 100% HTML, CSS e JavaScript puro!**

<img src="https://via.placeholder.com/1200x600/1a1a2e/9d4edd?text=BROKENtv+-+Player+IPTV+Moderno" alt="Banner BROKENtv" width="100%"/>

Um app de streaming IPTV completo que roda diretamente no navegador — funciona perfeitamente em **celular, PC, tablet e Smart TV** (WebOS, Android TV, etc.).

Zero instalação. Zero apps externos. Só abre o arquivo e assiste.

## ✨ Recursos Incríveis

- 🎨 **Design moderno e dark** com tons roxo/neon (gradientes, glow, animações suaves)
- 🔍 **Pesquisa instantânea** por nome do canal
- 🖼️ **Logos dos canais** com fallback inteligente (mostra iniciais se o logo não carregar)
- 📱 **Totalmente responsivo** – layout perfeito em qualquer tela
- 🎮 **Compatível com controle remoto** de Smart TV (navegação por setas + Enter)
- ⚡ **Player robusto** com Video.js + HLS.js (suporte a streams .m3u8)
- 🔒 **Tela de login simples** (salva usuário no localStorage)
- 📡 **Carrega canais de playlists M3U personalizadas**
- ♻️ **Remove duplicatas** automaticamente
- 🚀 **Leve e rápido** – tudo em um único arquivo HTML

## 🚀 Como Usar

1. Baixe o arquivo `index.html` deste repositório
2. Abra no seu navegador (Chrome, Firefox, Edge, etc.)
3. Na primeira vez, digite qualquer usuário e senha (é só pra dar um charme)
4. Pronto! Os canais vão carregar automaticamente

> Funciona offline depois do primeiro carregamento (exceto as streams e logos, claro)

## 🎨 Personalização

Quer deixar com a sua cara?

- Mude as cores no `:root` (variáveis `--primary`, `--accent`)
- Troque o nome no `<header>BROKENtv</header>`
- Adicione sua logo ou banner

É tudo CSS puro — fácil de customizar!

## 🛠️ Tecnologias Usadas

- HTML5 + CSS3 + Vanilla JavaScript
- [Video.js](https://videojs.com/) – Player profissional
- [HLS.js](https://github.com/video-dev/hls.js/) – Suporte a streams HLS
- Font Awesome (ícones)
- Zero dependências externas além de CDNs
